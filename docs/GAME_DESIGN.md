# LOTWORKS — ゲーム企画書 v0.1

更新: 2026-10-30 / 位置づけ: 企画段階の合意と仮説の整理

## 1. コアコンセプト
「Probably Stolen」型の小さなインベントリを主な操作空間とし、仕入れ・鑑定・修理・加工・製造・在庫管理・設備投資を行う経営ゲーム。独立した経済圏を持つ競合業者同士が、非同期オークションで商品や判断を交差させる。

目指す楽しさ:
- Stardew Valley型の生産・加工・蓄積・再投資の継続的な快楽を、コンパクトなUIで成立させる。
- 他の競合業者が作った商品に、通常のNPC商品にはない不確実性・意図・掘り出し物の可能性を見いだす。
- 同じ商品に「使用」「解体」「加工」「保有」「再出品」など異なる価値実現経路を持たせる。
- 単なる価格当てゲーム、単なる入札ボタン、単なる対人売上ランキングにはしない。

## 2. ステージ
### A. 個人店舗・工房（PvE）
- プレイヤーごとに独立した資金、在庫、設備、技術、進行度、ローカルNPC需要。
- 主な仕入れ源はオークションとしてよい。NPC供給は詰み防止やコンテンツ不足の補助候補。
- 仕入れた商品を鑑定、修理、分解、加工、製造、設備導入して価値を変える。
- ローカル販売・保有・再出品・事業投資を選ぶ。

### B. 非同期オークション（PvP）
- 出品者が準備した商品を他プレイヤーが査定・入札・購入する。
- 競売そのものが通常の仕入れ口であり、PvPは経営ループと分離しない。
- 他の参加者と同時接続する必要はない。
- 会場候補: ノミ市、素材オークション、機械オークション。進行度/専門分野によって使い分ける。
- ルール詳細は `AUCTION_DESIGN.md` を参照。

## 3. 基本ループ
1. 会場を選び、商品を観察・鑑定して仕入れる。
2. 工房で商品の状態・組成・能力を変える。必要なら設備を増設する。
3. 商品を使用・保管・ローカル販売・再出品のいずれかへ振り分ける。
4. 売却収益や生産能力によって経営を発展させ、さらに異なる仕入れと生産へ挑む。

## 4. ゲーム体験上の競争
- **出品者 vs 購入者:** 情報公開・加工意図・査定眼・落札判断が衝突する。
- **購入者 vs 他の入札戦略:** ゴースト入札等は検討候補で、具体的な競売方式は未決。
- **世界ごとの価値差:** 同じ商品でも設備、レシピ、所持素材、技術や目的によって評価が異なる。
- PvPを他プレイヤーの市場需要・売上シェアの奪い合いに還元しない。

## 5. 商品デザイン
- アイテム定義と、品質・故障・構成部品などを持つアイテム個体を区別する。
- 将来的には素材の純度や部品構成など、用途による価値差を作る。
- 外観以外の情報を不完全にする、虚偽の説明を可能にする等は検討段階。最初から詐欺を必須としない。
- ただのインベントリ整理を強制せず、整理が有意味な判断になるように設計する。

## 6. 会場（案）
| 会場 | 内容 | 主な技能 |
| --- | --- | --- |
| ノミ市 | ジャンク、中古品、未鑑定品 | 目利き、修理、価値判断 |
| 素材オークション | 原料、金属、薬品、中間材 | 純度評価、原価・生産計画 |
| 機械オークション | 機械、設備、ロボット、部品 | 故障診断、部品評価、設備投資 |

これらは段階的に実装する候補であり、MVPではノミ市のみを扱う。

## 7. 開発上の指針
- ソロ開発、Godot 4、2D/Control主体。
- ルールはできるだけ決定論的に扱い、広大な3Dワールドや大規模NPCシミュレーションを前提にしない。
- 新規性は「経営で生産した商品と、別人の価値判断が交わる競売」の接続にある。
- 生産・加工・鑑定の一つ一つの操作が楽しいかを、システム増設より先に検証する。

## 8. 研究上の位置づけ
- Phase 4 の「値踏み・持ち高・利確」と、商品を保有・加工・売却する意思決定が対応する。
- Phase 5 の「コミットメントと他者との衝突」を、同一世界の同期なしに商品スナップショットという媒体へ置き換える実験。
- これは研究から着想した**企画仮説**であり、遊びとしての成立を実証したものではない。
