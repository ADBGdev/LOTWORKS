# LOTWORKS — オークションへの持ち込み・消費とエクストラクション設計 v0.1

更新: 2026-10-31 / 設計検証メモ。各項目の状態を明記する。

## 1. 現時点の重要な合意
- **[確定]** 自分が拠点で所有しているアイテムをオークション会場に**持ち込む**。
- **[確定]** 持ち込みアイテムを会場で**使用する**。
- **[確定]** 使用したアイテムは**消費される**。恒久装備や持ち込み商品を単に担保として賭けることが主題ではない。
- **[方向性]** 対人の競争感とエクストラクション的緊張を強める。システム総量はむしろ減らす。
- **[確定]** 各プレイヤーの世界は経済的に独立し、非同期出品データを共有する原則は維持。

使用の意味は「使用時に実際に資産を消耗する」こと。**入場時に持ち込み品がすべて没収される**という意味ではない。

## 2. セッション案 — 確定ルールではない
1. **拠点:** 今回の参加に持っていく資金と消耗品を選ぶ。
2. **会場:** 他者が作った出品物・競合の判断に遭遇する。
3. **競売中:** どの商品・相手・局面で消耗品を使うか判断する。効果発動とともにその個体または使用回数が減る。
4. **購入:** 自分の入札と、競合の判断・商品情報・使用した道具の効果によって結果を得る。
5. **終了/撤退:** 商品や未使用品の扱いを解決して拠点に戻る。

補足: 複数ロットに連続参加し任意に撤退できる形式、持ち込み制限、使用回数制限、セッション失敗などは提案であり、現時点では未確定。

## 3. 消耗品の効果候補（未採用の例）
| 効果カテゴリー | 例 | 判断の種類 |
| --- | --- | --- |
| 鑑定 | 一品の隠し特性を一部開示 | 今知る必要があるか |
| 情報 | 競合の狙い・入札特性を調べる | 誰に対して使うか |
| 干渉 | 相手の行動・検査を一時的に妨げる | どのタイミングで切るか |
| 対抗 | 相手の干渉を防ぐ | 今守るか温存するか |

これらは可能性の提示に過ぎず、固定のアイテムリスト、ステータス異常、妨害システム、強制対戦仕様を意味しない。

## 4. 現時点で実在するコスト / 未完成のリスク
### 合意済み・自然に成立するもの
- 使用・消費した自分のアイテムの損失。
- 入札・購入で支払う資金、誤査定や割高落札による経済損失。
- 機会損失（使ってしまった道具は別の競売で使えない）。

### 未解決（アイテム消費だけでは解けない）
- **獲得済みの戦利品を失う条件**は必要か。必要なら、どの勝負でどの程度失うのか。
- 続行と撤退がどうトレードオフになるのか。撤退失敗やロストを入れるか。
- 競合業者の判断が、自分の結果にどの程度直接影響するか。
- 競合を実プレイヤーの保存済み行動として表現する際、どの情報とルールを保存するか。
- どのアイテムの消費が戦略的な楽しさにつながり、単なる作業や課金に見えないか。

「先へ進むほど戦利品が再入札で奪われる」「鑑定装備を担保にする」「アイテムを強制没収する」は、以前の**ブレインストーミング案**であって確定仕様ではない。実装を前提にしない。

## 5. PvPの手触りを強めるための検証観点
- 入札相手が単なる価格上昇関数でなく、人間の意図を持つ競合に見えるか。
- アイテムを使う対象・タイミング・温存に読み合いがあるか。
- 自分の拠点で積み上げたアイテムを消費したことが、勝敗や成果の実感を強めるか。
- 使用に失敗したとき、損失に納得できるか。
- PvPを強めても「仕入れた品を持ち帰って管理する」という日常の楽しさを壊さないか。

## 6. MVPテストの提案
オフライン模擬競売で一つの持ち込み消耗品を実装し、使った場合・使わなかった場合の違いを明示する。次に実プレイヤー由来の出品または行動データと対戦させる。「もう一回試したい」が生まれるかを先に見る。

**戦利品ロストが決まる前に、無理にエクストラクション完成形を実装しない。**
