# LOTWORKS — 設計決定ログ v0.2

更新: 2026-10-31 / 最初の合意を維持しつつ、2026-10-31の再設計を記録。

## 1. 明確に合意した前提
- [確定] 仮題 `LOTWORKS`、エンジン Godot 4.x。
- [確定] インベントリを主な操作空間とする、ソロ開発規模の経営＋非同期PvP企画。
- [確定] 各プレイヤーの経済は基本的に独立。グローバル需要シェアの奪い合いを主PvPにしない。
- [確定] 出品の瞬間に現物を出品者在庫から削除し、その状態をサーバーの出品データに残す。
- [確定] 同一出品情報は複数の購入者の競売で使われ、複数回購入され得る。
- [確定] 出品者の売却利益は、同一出品に対して**一度だけ**。追加購入数に応じた報酬はない。
- [確定] 全員のリアルタイム同時接続は必要ない。
- **[確定・新] 競売会場へ自分の所有するアイテムを持ち込む。**
- **[確定・新] 持ち込みアイテムを競売会場で実際に使用する。**
- **[確定・新] 使用したアイテムを消費する。** 持参品を単に担保に入れることや恒久的装備として扱うこととは異なる。

## 2. 目指す方向性（体験目標であり個別ルール未確定）
- [方向性] Probably Stolen型の仕入れ・鑑定・加工・在庫管理・蓄積の楽しさを、できるだけ小さい操作空間で成立させる。
- [方向性] **ゲームを複雑化せず**、エクストラクションの緊張感とPvP感を強める。
- [方向性] 仕入れの中心にオークションを置く。
- [方向性] 工房は拠点、オークションは競合との勝負の場所とする。初期は経営システムを絞る。
- [方向性] 会場は進行度・用途によって、ノミ市、素材、機械などへ拡張できる。
- [方向性] 消費するか温存するか、誰に・何に使うかが駆け引きになる。

## 3. 今回明確に否定・縮小した解釈
- [非採用] グローバル市場の需要奪い合いをPvPの中心とする。
- [非採用] 同じ出品の再購入に応じて出品者が何度も稼ぐロイヤリティ構造。
- [非採用] 持参品を単に「担保・物々交換」へ利用することを今回の核心とする解釈。
- [未採用] 「競売で負ければ持ち込み道具を没収」「落札品を当然奪われる」といったロスト規則。
- [保留] ダンジョン・罠師・生態系などを加える別路線。今の企画には追加せず、シンプルさを優先する。
- [保留] 多段階の製造・育成・巨大な工房経営を、初期MVPに入れること。

## 4. 未決定・次の設計課題
1. **何を消耗品として持ち込めるか**。商品と戦術アイテムを兼用するか。
2. **消費してどんな行為ができるか**。鑑定/情報/妨害/対抗は単なる候補。
3. **どんな対人競争が成立するか**。保存入札方針・相手行動の利用方法と結果表示。
4. **獲得済み戦利品の損失が生じるか**。生じるなら妥当な理由と仕組み。
5. **いつ撤退できるか**。撤退する価値と続行リスク。連続ロット形式自体も未確定。
6. 持ち込み制限、アイテム使用コスト/不発時の消費、未使用品の帰還時処理。
7. 一回限りの売却利益を、いつ・どう確定するか。
8. 同一購入者の同一listing複数購入、再提示頻度、悪用防止。
9. オークションの入札方式、NPC不足補完、サーバー構成。
10. 商品の鑑定・加工・成長を最小どこまで作るか。

**設計上の注意:** 現時点で成立しているリスクは、資金損失に加えて「自分のアイテムを実際に使って消費する」こと。これはエクストラクションに近づく一歩であり、全ロストや戦利品強奪の実装が合意されたことを意味しない。

## 5. MVPの優先検証
1. 持ち込む物を選ぶこと、使うか温存することが楽しいか。
2. 人間の出品物と競合の判断が、その使用判断に影響するか。
3. 取得品の整理・加工・再出品が次の競売を動機づけるか。
4. 撤退と戦利品リスクの追加が本当に必要か（後段で検証）。
