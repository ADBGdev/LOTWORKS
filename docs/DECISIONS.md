# LOTWORKS — 設計決定ログ

更新: 2026-10-30。会話で合意した方針と、今後の議論を区別する。

## 決定・合意
- [確定] 仮題: **LOTWORKS**。
- [確定] エンジン: **Godot**（初期構成はGodot 4.xを採用）。
- [方向性] Probably Stolen型のインベントリ中心の生産・経営ゲームに、非同期PvPを結びつける。
- [方向性] 主な調達経路をオークションとする構造は採用可能で、企画の中心候補。
- [確定] 各プレイヤーのゲーム世界・ローカル経済は原則として独立。共有需要の奪い合いは主軸にしない。
- [確定] **出品時に出品者の在庫から商品を削除**。
- [確定] 出品情報をサーバーに保存し、最初の購入後も再利用してよい。
- [確定] 一つの出品データを**複数の購入者が独立して購入**することがあり得る。
- [確定] **出品者の売却利益は一回のみ**。再購入回数に連動する報酬は付けない。
- [方向性] 会場はノミ市・素材・機械など複数。進行度や需要で区別する。
- [方向性] リアルタイムの同時接続を必要としない。

## 未決定
- 一回の売却利益が確定するタイミングと金額計算。
- PvPとしての入札競合・対人の手応えをどのルールで成立させるか。
- 商品品質・欠陥・査定・隠蔽・偽装の範囲。
- 同じ出品データを同じ購入者が複数回買えるか。
- 出品アーカイブの利用回数、掲載期間、推薦規則。
- 商品パラメータ、加工レシピ、設備成長の設計。
- プレイヤー出品が不足した時のNPC補充方式。
- サーバー実装、運用、チート対策と通貨の発行源。
- MVPの具体的なアイテム数、検査手段、競売形式の確定。

## 試作時の優先検証
1. 自分で商品を値踏み・加工・再出品する行為が楽しいか。
2. 他プレイヤー製の商品が、NPC商品の上位の体験になるか。
3. 出品と購入双方のプレイヤー判断が、本当にぶつかるか。

変更時はこのログと関連仕様書を同じコミットで修正する。
