# LOTWORKS — MVP / 検証計画 v0.2

更新: 2026-10-31 / 複雑な生産経営から、競売での持ち込み消耗品と対人判断へ検証順序を変更。

## 最重要の仮説
**自分の貴重なインベントリアイテムを選んで持ち込み、競売中に使用・消費することで、相手の判断と関わる戦略が生まれ、単なる資金勝負よりも面白くなるか。**

同時に、出品商品を買い、拠点へ戻して活用する楽しさを損なわないかを確認。

## 試作範囲の候補（未確定）
- Godot 4.x / GDScript / 2D Control UI。
- ノミ市1会場。素材・機械・生態系などの追加モードは不要。
- まず少数の商品個体と不完全な情報を用意（商品数は目安であり確定していない）。
- 「持ち込み選択 → 鑑定/入札 → アイテム使用・消費 → 結果 → 拠点帰還」を一巡させる。
- **最初は1〜2種類の消耗品の効果を試験する**（仮スコープ）。
- 拠点機能は在庫、簡単な加工または修理、売却・出品に限定。
- 他プレイヤーの保存出品物または保存行動を使う。まずはローカルデータで試験可能な構成。
- まず実際のロストを追加せず、消耗と対人性を評価する。ロストは仕様が明確になってから独立に判断する。

## 開発ステップ
### 0. 初期セットアップ（完了）
Godot起動シーン、空フォルダ、設計ドキュメント。実ゲームロジック未実装。

### 1. 持ち込み消耗品のミニゲーム
在庫から持参品を選び、競売中にターゲットを決めて使い、正確に消費する。使わない選択肢も設ける。

### 2. 仕入れ・持ち帰り・経営循環
商品を査定・購入し、拠点で簡易加工/保管/売却する。使用した消耗品が再補充の対象になる。

### 3. プレイヤー由来の非同期対戦
他人の出品スナップショットを複数の独立購入者が使えること、出品者利益が一度きりであることを検証。さらに、プレイヤー由来の競合行動が消耗品の使用判断を変えるか確認。

### 4. エクストラクション要素の検証
前段までが面白ければ、撤退判断と戦利品リスクの必要性・具体的なルールを別途比較する。**勝手に全ロスト・没収を採用しない。**

## 成否の判定
- どのアイテムを持参するかに迷うか。
- 使用する対象とタイミングに判断があるか。温存が意味を持つか。
- 消費が「損をした」だけでなく「勝負のために払った」と感じられるか。
- 他プレイヤーの実際の意図が競争に見えるか。
- 落札品を持ち帰ったあとの保管・加工・売却が次の勝負の動機になるか。
- システムの追加なしで、繰返し挑戦したくなるか。

## 非目標
- リアルタイム対戦、グローバル共通市場、複雑なNPC経済。
- 大量の工場設備、長い生産チェーン、複数会場の同時実装。
- 3D移動、探索ダンジョン、複雑な生態系。
- 多量の固有消耗品・スキル・状態異常を最初から実装すること。
- 根拠のない略奪/担保/道具ロストの強制。
